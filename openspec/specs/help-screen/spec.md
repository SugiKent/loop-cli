## Requirements

### Requirement: ? はヘルプ画面を開き、? か Esc で開いた画面に戻る
`Model` は画面の状態として、s10 までの 4 つ（キュー / カード詳細 / PR 詳細 / 確認）に加えて ヘルプ を MUST 持つ（s09 `card-detail`「Enter でカード詳細を開き、Esc で 1 つ前の画面に戻る」の MODIFIED を見る）。`Update` は MUST 次のとおり扱う。
- キュー画面 / カード詳細画面 / PR 詳細画面で `?`: 戻り先（`?` を押した画面）を保持してヘルプ画面に移る。キュー画面の現在のタブと選択行、詳細の対象・選択中の PR・展開状態・スクロール位置は変えない
- 確認画面（s10）で `?`: 何もしない（s10「他のキー: 何もしない」のまま。回答の途中でヘルプに移らない）
- ヘルプ画面で `?` または `Esc`: 戻り先の画面に戻る。戻り先の状態（タブ・選択行・詳細の対象・選択中の PR・展開状態・スクロール位置）は開く前のまま。戻り先がカード詳細 / PR 詳細なら本文領域の内容と寸法を作り直す（ヘルプ中に端末サイズが変わっても詳細に反映されないため。スクロール位置は先頭に戻さない）（閉じるキーは mvp.md に無く、design.md 未決事項の既定値）
- ヘルプ画面で `q` / `Ctrl+C`: 終了コマンドを返す（s09「どの画面でも q で終了する」）
- ヘルプ画面で他のキー（`j` / `k` / `1`〜`4` / `Enter` / `a` / `t` / `o` / `R` / `x` / `g` / `p` を含む）: 何もしない
ヘルプ画面を開いている間に取得完了（s08 `fetchedMsg`）、回答の投稿結果（s10）、切り替えの結果（s11）、ブラウザで開く結果（s12 `browse-open`）のメッセージが届いたら、各 change の規則どおりに処理し（`Cards` と最終更新時刻の更新、ステータスの表示）、画面はヘルプのままにする。端末サイズの変更も受け取り、ヘルプ画面の幅と高さに反映する。

#### Scenario: キューから開いて ? で戻る
- **WHEN** `example` の `Result` を渡してバックログタブを選んだ `Model` に `?` を与え、次にもう一度 `?` を与える
- **THEN** 1 回目の後の画面はヘルプで、2 回目の後の画面はキューで、現在のタブはバックログ、選択行の添字は 0 のままである

#### Scenario: カード詳細から開いて Esc で戻る
- **WHEN** `example` の issue 108 のカード詳細を開き `x`（展開）を与えた `Model` に `?` を与え、次に `Esc` を与える
- **THEN** 1 回目の後の画面はヘルプで、2 回目の後の画面はカード詳細で、詳細の対象は issue 108 の Card のまま、routine コメントは展開されたままである（`View` に `(+1 行)` が無い）

#### Scenario: PR 詳細から開いて戻る
- **WHEN** `example` の issue 108 のカード詳細から `Enter` で PR 131 の PR 詳細を開いた `Model` に `?` を与え、次に `Esc` を与える
- **THEN** 2 回目の後の画面は PR 詳細で、対象は PR 131 である

#### Scenario: 確認画面で ? は何もしない
- **WHEN** s10 の手順で blocked-by の確認画面に移った `Model` に `?` を与える
- **THEN** 画面は確認画面のままで、コマンドは返らない

#### Scenario: ヘルプ画面で他のキーは何もしない
- **WHEN** `example` の `Result` を渡してヘルプ画面を開いた `Model` に `j`、`2`、`Enter`、`a`、`t`、`o`、`R`、`x`、`g`、`p` を 1 つずつ与える
- **THEN** どのキーでもコマンドは返らず、画面はヘルプのままで、キュー画面の現在のタブと選択行は変わらず、`Fake.Calls` は空でスタブ `Editor` は呼ばれない

#### Scenario: ヘルプ画面でも q で終了する
- **WHEN** ヘルプ画面を開いた `Model` に `q` を与える
- **THEN** 終了コマンドが返る

#### Scenario: ヘルプを開いている間の取得完了は反映される
- **WHEN** `example` の `Result` で今やるタブを表示しヘルプ画面を開いた `Model` に、issue 108 の Card を含まない `Result` を取得完了として渡し、`?` でキューに戻る
- **THEN** 取得完了の後も画面はヘルプのままで、戻った後の今やるタブの行は新しい `Result` のものである

### Requirement: ヘルプ画面は実装済みのキーだけを一覧する
ヘルプ画面の `View` は、端末の幅と高さの全体を使い、上から MUST 次の順で描く。
1. 見出し `キーバインド`
2. 空行
3. キーの行。各行は、キーの表記を表示幅 16 に空白で埋めた列に続けて動作の説明を置く（`<キー（16 列）><説明>`）。行の順序と内容は次のとおりで、この change の時点で実装済みのキーだけを出す。前半は mvp.md キーバインド表の順、後半は表に無いキー（s09 / s08 の design.md 未決事項で決めたもの）である

```
j / k / ↑ / ↓   行移動（キュー）/ スクロール（詳細）
1–4 / Tab       タブ切替（今やる / バックログ / 進行中 / 異常）
Enter           詳細を開く / PR を開く（カード詳細）
a               回答・コメント（$EDITOR を開く）
t               stage:todo を付ける / 外す
o               ブラウザで開く
g               PR ↔ issue を相互ジャンプ（詳細）
R               全件再取得（キュー）
?               ヘルプを開く / 閉じる
q               終了
Esc             1 つ前の画面に戻る（詳細 / ヘルプ）
Tab             PR 選択（カード詳細）
x               routine コメントの展開 / 折りたたみ（詳細）
PgUp / PgDn     ページ単位のスクロール（詳細）
```

4. 残りの高さは空行
5. 最終行はフッタ。左は `? / Esc 閉じる  q 終了`、右は s08 と同じステータス（スピナー / エラー / 書き込みステータス）

mvp.md キーバインド表にあって未実装のキー（`v` / `h` / `l` / `←` / `→` / `A` / `s` / `m` / `n` / `/`）は出さない。`p` は s21 でキュー画面の 2 ペインが常設になり切替の意味を失ったので出さない。後続 change は自分のキーを実装したときに、この Requirement を MODIFIED で写して行を足す（s14 `m`、s15 `n` / `s`、s16 `A`、s17 `v` / `h` / `l` / `←` / `→`、s19 `/`）。見出しと空行とキーの行が端末の高さ − 1（フッタ）に収まらないときは末尾から切り、スクロールは持たない（design.md 未決事項の既定値。行数は 17 で、`Model` の既定の高さ 24 に収まる）。各行は端末の幅で切り詰める。

#### Scenario: 実装済みのキーの行が順に出る
- **WHEN** `example` の `Result` を渡してヘルプ画面を開いた `Model`（幅 80・高さ 24）の `View` から ANSI エスケープを除いて読む
- **THEN** 1 行目は `キーバインド` で、`j / k / ↑ / ↓` と `行移動（キュー）/ スクロール（詳細）` を含む行、`o` で始まり `ブラウザで開く` を含む行、`R` で始まり `全件再取得（キュー）` を含む行、`?` で始まり `ヘルプを開く / 閉じる` を含む行、`PgUp / PgDn` で始まり `ページ単位のスクロール（詳細）` を含む行がこの順で含まれ、キーの行は 14 行である

#### Scenario: 切替を失った p の行は出ない
- **WHEN** 同じ `View` を読む
- **THEN** `表とプレビューの切替` を含む行は無い

#### Scenario: 未実装のキーは出ない
- **WHEN** 同じ `View` を読む
- **THEN** `merge`、`新規`、`即着手`、`カンバン`、`絞り込み`、`review thread` は含まれない

#### Scenario: ヘルプ画面のフッタ
- **WHEN** 同じ `View` を読む
- **THEN** 最終行に `? / Esc 閉じる` と `q 終了` が含まれ、`Enter 開く` と `1-4/Tab タブ` は含まれない

#### Scenario: 低い端末では末尾の行を切る
- **WHEN** ヘルプ画面を開いた `Model` に幅 80・高さ 10 のサイズメッセージを与え、`View` から ANSI エスケープを除いて読む
- **THEN** 行数は 10 で、1 行目は `キーバインド`、最終行はフッタ（`? / Esc 閉じる` を含む）であり、`PgUp / PgDn` で始まる行は含まれない

#### Scenario: ヘルプ画面でも取得中のスピナーが出る
- **WHEN** `New` 直後（初回取得中）の `Model` に `?` を与え、`View` から ANSI エスケープを除いて読む
- **THEN** 1 行目は `キーバインド` で、最終行に `取得中` が含まれる
